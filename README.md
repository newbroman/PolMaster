# Polish Phrase Master (v17)

> **Archived.** This is an earlier version, kept for reference. The current app is **Polish Phrase Master**: [repo](https://github.com/newbroman/Polish_survival_phrases) · [live app](https://newbroman.github.io/Polish_survival_phrases/).

An earlier build of Polish Phrase Master: survival Polish phrases organised into levels, with flashcards and speech.

**Live (frozen) app:** https://newbroman.github.io/PolMaster/

## Files

A static web app with no build step: `index.html`, `manifest.json`, `service-worker.js`, and the phrase levels in `phrases_*.json`.

To run it locally: `python3 -m http.server`, then open http://localhost:8000.
